# BotIQ demo sites

These are **fictional** businesses made for BotIQ product demonstrations:

- Crestline Realty — `/crestline-realty/`
- Willow & Vow — `/willow-and-vow/`
- Summit Ridge Dental — `/summit-ridge-dental/`

None of them is a real company, and any resemblance to a real business or
person is coincidental. Phone numbers use the fictional 555-01xx range and
email addresses use the reserved `.example` domain. Every page carries a
`noindex` tag so search engines leave them out.
